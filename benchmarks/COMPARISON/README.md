# Model Comparison

Comparison of forecasting models evaluated on DATASET_MULTIMODAL_V8.

Included models:

- LightGBM
- XGBoost
- CatBoost
- Random Forest

Included analyses:

- Forecasting performance comparison
- Model ranking
- Friedman test
- Pairwise Wilcoxon tests
- Nowcasting vs Forecasting comparison

Main files:

- benchmark_summary.xlsx
- forecasting_models.csv
- forecasting_ranking.csv
- friedman_test.csv
- pairwise_wilcoxon.csv
- BENCHMARK_REPORT.md
