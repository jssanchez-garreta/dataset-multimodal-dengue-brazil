# Benchmarks

This directory contains benchmark experiments and results associated with DATASET_MULTIMODAL_V8.

Included models:

- LightGBM
- XGBoost
- CatBoost
- Random Forest

Evaluation settings:

- Nowcasting
- Forecasting

Validation strategy:

- Temporal expanding-window validation

Statistical analysis:

- Friedman test
- Wilcoxon signed-rank tests
